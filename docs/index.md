# Asterism

Asterism is a macOS desktop workspace for running coding agents such as Claude Code. Every task gets
its own git branch and worktree, agents run in persistent sessions managed by a background daemon,
and pull request status flows back into the sidebar.

- **[Install Asterism](guide/install.md)** and add your first project.
- **[Projects and tasks](guide/projects-and-tasks.md)** explains the core workflow.
- **[Writing plugins](developer/writing-plugins.md)** shows how to extend Asterism.
